= Source baseline and compatibility
:description: Trace the eniLINK capabilities used by Pod to their upstream implementation.

The platform documentation describes eniLINK through its use in LinkedFactory Pod.
It is based on https://github.com/enilink/enilink/tree/{enilink-source-revision}[eniLINK revision {enilink-source-revision}].
The Pod build declares an eniLINK snapshot dependency; a snapshot version alone does not identify an immutable upstream revision.

[IMPORTANT]
====
Source availability is not deployment availability.
Check the installed bundles, RDF readers and writers, configuration, and endpoint permissions in the Pod distribution you run.
This documentation does not claim that optional upstream functionality is enabled by default.
====

== Choose an interface by responsibility

Use xref:api-reference:models.adoc[] for asset-description graphs, xref:api-reference:files.adoc[] for attachment bytes, and xref:api-reference:time-series.adoc[] for measurements.
Use xref:platform-basics:sparql.adoc[] to query descriptions or join them with KVIN data.
Keep configuration graphs and access-control metadata separate from ordinary asset imports.
