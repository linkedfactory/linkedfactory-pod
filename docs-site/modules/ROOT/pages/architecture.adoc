= Architecture
:description: Understand how Pod connects industrial data services to eniLINK's semantic platform.

LinkedFactory Pod runs as domain functionality on an Eclipse Equinox/OSGi platform.
Its bundles integrate with eniLINK's model management and web framework.

== Asset descriptions and measurements

eniLINK manages RDF and OWL models through a configured repository.
Pod's KVIN store manages time-series values associated with item, property, context, time, and sequence identifiers.

The default service configuration selects a LevelDB-backed value store.
Other storage implementations require explicit configuration.
Changing time-series storage does not automatically change the RDF repository.

eniLINK also maintains model metadata and a separate file store for attachments.
Use xref:api-reference:models.adoc[] for graph exchange and xref:api-reference:files.adoc[] for document bytes.
Neither interface substitutes for the time-series API.
See xref:platform-basics:configuration.adoc[] for configuration discovery and storage boundaries.

[IMPORTANT]
====
The supplied server configuration selects an in-memory RDF model set.
A persistent workspace or a persistent time-series store alone does not guarantee persistence of asset descriptions.
Configure and verify both storage paths.
====

== Query integration

Use ordinary SPARQL patterns for asset descriptions.
Use `SERVICE <kvin:>` for measurements, then join on shared resource identifiers.

See xref:user-guide:querying-data.adoc[] for complete requests and xref:platform-basics:managing-models.adoc[] for model selection.
