= LinkedFactory Pod
:description: Connect industrial asset descriptions and time-series measurements using LinkedFactory Pod.

LinkedFactory Pod connects descriptions of industrial assets with their measurements.
Use it to describe equipment, ingest observations, and query relationships and measurements through shared identifiers.

Pod implements the https://github.com/linkedfactory/specification[LinkedFactory architecture] on top of https://github.com/enilink/enilink[eniLINK].
You work with one application: eniLINK supplies its semantic platform capabilities, while Pod adds industrial data services and time-series integration.

== One identifier connects descriptions and measurements

An asset such as `https://example.org/Press/Frame/StrainGauge` can appear in both:

* An RDF model containing its type, label, and relationships.
* A measurement series identified by that asset IRI and a property IRI such as `p:force`.

RDF describes relationships as subject, predicate, and object.
Pod's KVIN data model adds time to associate a value with an item and property.
A context can distinguish datasets; sequence numbers can distinguish measurements sharing a timestamp.

[NOTE]
====
RDF descriptions and time-series measurements are related but are not interchangeable storage representations.
Writing a measurement does not establish a complete asset ontology.
An ordinary RDF query does not automatically scan the time-series store.
====

== Platform integration beyond measurements

Use eniLINK's RDF model API for Turtle and JSON-LD asset descriptions and its file API for binary attachments.
The SPARQL endpoint supports semantic queries and RDF updates; Pod adds KVIN measurement queries to that interface.
These APIs have different payloads, lifecycle semantics, and authorization requirements.

Start with xref:platform-basics:semantic-concepts.adoc[] to distinguish model, asset, ontology, and measurement identifiers.
See xref:ROOT:sources.adoc[] for the upstream implementation baseline and optional-feature boundaries.

[IMPORTANT]
====
The supplied development configuration is not a production security baseline.
Review anonymous access, administrator credentials, persistent storage, TLS, and endpoint authorization before exposing a Pod.
====
