= Enable full-text search
:description: Index RDF literals in an external search server and query them through SPARQL.

Pod can send RDF statements to a search server and expose keyword search in SPARQL through `SERVICE <fts:>`.
This guide sets up the built-in Elasticsearch backend.

[WARNING]
====
The JSON payloads for bulk indexing and search requests are not yet stable and may change.
Example payloads are in `bundles/io.github.linkedfactory.core/src/test/resources/fts/`.
====

== Prerequisites

* A search server that accepts bulk requests at `POST {fts:endpoint}{fts:bulkPath}` with `Content-Type: application/json`.
* Access to the repository configuration of your Pod (see xref:reference:configuration.adoc[]).

== Add the FTS SAIL to the repository

Wrap the RDF store with `fts:FtsSail` inside the KVIN SAIL.
`configurations/default-with-search.ttl` contains a complete example.

[source,turtle]
----
@prefix models: <http://enilink.net/vocab/komma/models#> .
@prefix rep: <http://www.openrdf.org/config/repository#>.
@prefix sr: <http://www.openrdf.org/config/repository/sail#>.
@prefix sail: <http://www.openrdf.org/config/sail#>.
@prefix ns: <http://www.openrdf.org/config/sail/native#>.
@prefix fts: <http://linkedfactory.github.io/config/sail/fts#>.

<urn:enilink:data> a models:RepositoryModelSet ;
    models:repository <urn:linkedfactory:data-repo> .

<urn:linkedfactory:data-repo> a rep:Repository ;
  rep:repositoryID "linkedfactory-data" ;
  rep:repositoryImpl [
    rep:repositoryType "openrdf:SailRepository" ;
    sr:sailImpl [
      sail:sailType "kvin:KvinSail" ;
      sail:delegate [
        sail:sailType "fts:FtsSail" ;
        fts:backend "elastic" ;
        fts:endpoint "http://localhost:9200" ;
        fts:bulkPath "/fts/bulk" ;
        fts:searchPath "/fts/_search" ;
        fts:defaultLimit 100 ;
        fts:failOnError true ;
        sail:delegate [
          sail:sailType "openrdf:NativeStore" ;
          ns:tripleIndexes "cspo,cpos,spoc,posc"
        ]
      ]
    ]
  ] .
----

To use an in-memory store, replace `openrdf:NativeStore` with `openrdf:MemoryStore`.
All properties are described in xref:reference:full-text-search.adoc[].

== Query by keyword

Combine the keyword search with ordinary graph patterns:

[source,sparql]
----
prefix fts: <fts:>
prefix dtsc: <https://example.org/dtsc/>

select ?iri ?score where {
  service <fts:> {
    ?iri fts:keywords "some keywords" ;
         fts:score ?score .
  }
  ?iri dtsc:weight ?weight .
  filter (?weight > 50)
}
----

To query a different search server for a single request, put its address in the service IRI, for example `SERVICE <fts:http://host:9200>`.
