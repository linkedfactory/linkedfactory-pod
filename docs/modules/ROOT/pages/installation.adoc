= Install Pod
:description: Run LinkedFactory Pod from the Docker image, with Docker Compose, or from source.

Pod is distributed as a Docker image.
For development you can also build and run it from source.

== Docker image

Images are published on https://hub.docker.com/r/linkedfactory/linkedfactory-pod[Docker Hub].

[source,bash]
----
docker run -p 8080:8080 \
  -v linkedfactory-pod-workspace:/linkedfactory-pod/workspace \
  linkedfactory/linkedfactory-pod
----

Pod is then available at http://localhost:8080/linkedfactory/.
Continue with xref:ROOT:quickstart.adoc[].

== Docker Compose

`docker/docker-compose.yml` builds the image from the local build output and mounts workspace and deploy directories on the host.
Build Pod first (`mvn package`), then follow xref:how-to:deploy-with-docker-compose.adoc[].

== From source

Building and starting Pod from source is described for contributors in xref:development:build-and-run.adoc[].

== Before going to production

The supplied configuration is meant for development: it contains default credentials and keeps asset descriptions in memory.
Read xref:how-to:secure-deployment.adoc[] and xref:explanation:storage-and-persistence.adoc[] first.
