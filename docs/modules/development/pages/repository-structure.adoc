= Repository structure
:description: Directories and bundles of the linkedfactory-pod repository.

[cols="1,3",options="header"]
|===
|Path |Content

|`bundles/io.github.linkedfactory.core`
|KVIN data model and stores (LevelDB, Parquet, partitioned, HTTP client), RDF4J integration (`kvin:` SAIL and service, `fts:` SAIL, AAS federation), CLI.

|`bundles/io.github.linkedfactory.service`
|Service layer on eniLINK/Lift: `/linkedfactory/values` API, store factories, MQTT bridge, web views, default OSGi configuration.

|`bundles/io.github.linkedfactory.opcua`
|Conversion of OPC UA NodeSets to RDF.

|`features/`
|Karaf feature definition of the Pod bundles.

|`server/`
|Assembly of the runnable server distribution (`server/target/assembly`).

|`launch/equinox/`
|Launch configuration to run Pod from the build with Maven.

|`configurations/`
|Example platform configurations (`default.ttl`, `default-with-search.ttl`) and `jaas.conf`.

|`docker/`
|Dockerfile, entrypoint, and Docker Compose file.

|`releng/`
|Release tooling: version update script, license header.

|`docs/`
|This documentation (Antora component) and the documentation plan in `docs/diataxis/`.

|`.github/workflows/`
|CI: build and verify, Maven deploy, Docker image, documentation build.
|===
